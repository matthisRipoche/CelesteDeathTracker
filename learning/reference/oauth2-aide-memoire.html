OAuth2 avec Discord

Rôles

Resource ownerLe joueur
ClientTon API (pas le navigateur)
Authorization serverDiscord

Le flux en 6 étapes

  1. Clic → GET /api/auth/oauth2/discord
  2. Redirection vers Discord (client_id, scope, redirect_uri, state)
  3. Le joueur autorise chez Discord
  4. Retour avec ?code=…&state=…
  5. API → Discord : code + secret client → access token
  6. API → Discord : /users/@me avec le token → id, pseudo, avatar

DonnéeNavigateurSecret ?

Grille de relecture

  1. Qui est le client ? Le serveur, secret en variable d'environnement.
  2. Quel scope ? Le minimum (identify).
  3. Qu'est-ce qui protège le retour ? state + adresse de retour identique chez Discord.
  4. Que devient l'identité ? Un compte du site + une session ordinaire.
